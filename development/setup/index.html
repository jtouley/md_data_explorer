    Development Setup

    Environment Setup

    1. Install Prerequisites

    # Python 3.10+
python --version

# uv (recommended package manager)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Or use pip
pip install --upgrade pip

    2. Clone Repository

    git clone https://github.com/yourusername/md_data_explorer.git
cd md_data_explorer

    3. Create Virtual Environment

    # With uv (recommended)
uv venv
source .venv/bin/activate  # Linux/Mac
# Or: .venv\Scripts\activate  # Windows

# Or with venv
python -m venv .venv
source .venv/bin/activate

    4. Install Dependencies

    # Install all dependencies including dev dependencies
uv sync

# Or with pip
pip install -e ".[dev]"

    IDE Configuration

    VS Code

    Install extensions:

    • Python (Microsoft)
    • Pylance
    • Black Formatter
    • isort

    Settings (.vscode/settings.json):

    {
  "python.linting.enabled": true,
  "python.linting.pylintEnabled": false,
  "python.linting.mypyEnabled": true,
  "python.formatting.provider": "black",
  "editor.formatOnSave": true,
  "python.sortImports.args": ["--profile", "black"]
}

    PyCharm

    1. Set Python interpreter to .venv/bin/python
    2. Enable "Black" as code formatter
    3. Enable "isort" for import sorting
    4. Configure mypy as external tool

    Running the Application

    Desktop app (FastAPI + Electron)

    make run                            # FastAPI backend on http://127.0.0.1:8000
cd electron && npm ci && npm start  # Electron desktop app (separate terminal)

    API docs at http://127.0.0.1:8000/api/docs

    CLI (if implemented)

    clinical-analytics serve
clinical-analytics analyze --dataset covid-ms --query "compare mortality by treatment"

    Development Tools

    Code Formatting

    # Format all code
black src/ tests/
isort src/ tests/

# Check formatting without changes
black --check src/ tests/

    Type Checking

    # Run mypy
mypy src/

# With strict mode
mypy --strict src/

    Linting

    # Run flake8
flake8 src/ tests/

# Run pylint
pylint src/

    Testing

    # Run all tests
pytest tests/

# Run with coverage
pytest tests/ --cov=src/clinical_analytics --cov-report=html

# Run specific test
pytest tests/test_nl_query_engine.py::test_pattern_matching

# Run with verbose output
pytest tests/ -v -s

    Documentation

    # Serve documentation locally
mkdocs serve

# Build documentation
mkdocs build

# Deploy to GitHub Pages
mkdocs gh-deploy

    Database Setup

    DuckDB

    No setup required - DuckDB runs in-memory by default.

    For persistent storage:

    import duckdb

# Create persistent database
conn = duckdb.connect('clinical_data.db')

# Use in semantic layer
semantic_layer = SemanticLayer(df, config, backend='duckdb', db_path='clinical_data.db')

    Environment Variables

    Create .env file (not committed to git):

    # Optional: Anthropic API key for Tier 3 LLM fallback
ANTHROPIC_API_KEY=your_key_here

# Optional: Logging level
LOG_LEVEL=INFO

# Optional: Data directory
DATA_DIR=./data

    Load with:

    from dotenv import load_dotenv
load_dotenv()

    Troubleshooting

    Import Errors

    # Reinstall in editable mode
pip install -e .

    DuckDB Issues

    # Upgrade DuckDB
pip install --upgrade duckdb

    API Port Conflicts

    # API-only on another port (the desktop app expects 8000)
uv run python -m clinical_analytics.api.serve --port 8001

    Test Failures

    # Clear pytest cache
pytest --cache-clear

# Run with verbose output
pytest tests/ -v -s --tb=short

    Type Checking Errors

    # Ignore specific errors
mypy src/ --no-strict-optional

    Debugging

    API Debugging

    Run make run-api and use http://127.0.0.1:8000/api/docs to call routes directly. Logs are structured (structlog); bind context with logger.bind(dataset_id=...).

    Pytest Debugging

    # Drop into debugger on failure
pytest tests/ --pdb

# Drop into debugger at start of test
pytest tests/ --trace

    VS Code Debugging

    Add .vscode/launch.json:

    {
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Python: FastAPI",
      "type": "python",
      "request": "launch",
      "module": "uvicorn",
      "args": ["clinical_analytics.api.main:app", "--host", "127.0.0.1", "--port", "8000"]
    },
    {
      "name": "Python: Pytest",
      "type": "python",
      "request": "launch",
      "module": "pytest",
      "args": ["tests/", "-v"]
    }
  ]
}
