## Governance

This is a single-maintainer project. The maintainer:

- reviews and merges pull requests, and owns every path (`.github/CODEOWNERS`);
- triages issues and handles private vulnerability reports ([SECURITY.md](SECURITY.md));
- enforces the [Code of Conduct](CODE_OF_CONDUCT.md);
- holds the repository's settings, secrets (the Codecov token) and GitHub Pages deployment.

Decisions are made by the maintainer, in public issues and pull requests where possible. Anyone
can propose a change by opening an issue. Write access is granted only after a record of reviewed
contributions, and any new maintainer is added to this file in the same pull request.
